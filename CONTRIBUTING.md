# Участие в BUTTON-S

Спасибо за интерес к BUTTON-S. Проект небольшой и развивается в одном основном репозитории. Перед крупной работой лучше сначала открыть обращение (issue) и согласовать направление.

## Лицензия и исходники

BUTTON-S распространяется по модели **source-available**, а не как программа с открытым исходным кодом. Официальные сборки можно бесплатно использовать в любых целях, включая коммерческие. Модификация приложения и перепродажа/лицензирование приложения или его изменённых версий требуют предварительного письменного разрешения автора. Исходники открыты для просмотра в публичном репозитории; изменять, публиковать или распространять их без разрешения нельзя. Подробности — в [LICENSE.md](LICENSE.md).

Отправляя пул-реквест, патч, документацию или другой материал, вы подтверждаете, что имеете право его отправить, и предоставляете автору право использовать, изменять и распространять вклад в составе BUTTON-S. Авторство BUTTON-S (`BUTTON-S by Михаил Базаров (bazarow.ru)`) должно сохраняться.

## Что можно предлагать

- баг-репорты с шагами воспроизведения;
- небольшие исправления и тесты;
- улучшения документации;
- исправления для macOS и движка ввода;
- идеи по UX, словарям, голосу и ИИ — сначала как обращение (issue).

Windows/Linux пока не поддерживаются; платформенные PR по ним стоит сначала обсудить.

Не присылайте реальный набранный текст, аудио, ключи, токены, пароли, модели, приватные IP и рабочие пути. Для примеров используйте вымышленные имена, домены (`example.ru`) и адреса из TEST-NET.

## Локальная сборка

Нужны Node.js 20+, Rust stable, Xcode Command Line Tools и CMake (для `llama-cpp-2` и `whisper-rs`):

```bash
npm install
npm run tauri dev
```

Проверки перед PR:

```bash
npm run check
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets
npx tauri build
```

Не коммитьте `node_modules`, `dist`, `src-tauri/target`, `src-tauri/gen`, модели, базы и локальные конфиги — они в `.gitignore`. Модели и ключи не входят в репозиторий: они лежат в `~/Library/Application Support/com.button.s/` и Keychain.

## Стиль

- Интерфейс и пользовательские тексты — на русском и английском (оба словаря `src/lib/i18n.ts`).
- Код и идентификаторы — английские.
- CSS — обычные классы, без Tailwind и новых UI-фреймворков.
- Не добавляйте комментарии без необходимости; следуйте стилю соседних файлов.
- Маленькие изменения проще проверять: один PR — один смысл.
- Не добавляйте секреты, набранный текст, аудио и реальные данные пользователей ни в код, ни в тесты, ни в скриншоты.

## Пул-реквест

1. Опишите проблему и решение.
2. Добавьте или обновите тесты, если меняется поведение.
3. Приложите скриншот для изменений интерфейса.
4. Убедитесь, что контроль качества пройден.
5. Не коммитьте артефакты сборки, модели и локальные конфиги.
